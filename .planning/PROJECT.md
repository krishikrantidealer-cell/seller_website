# EBS BioCrop Science - Farmer E-Commerce Platform

## Project Overview
- **Name:** EBS BioCrop Science E-Commerce Platform (`seller_website`)
- **Target Audience:** Indian farmers, progressive growers, Krishi Kendras, and rural agribusinesses.
- **Brand Identity:** EBS Essential Bio Crop Science (derived strictly from logo: `#0F3E16` Forest Dark, `#1B5E20` Primary Green, `#E65100` Harvest Amber, `#B71C1C` Brand Red).
- **Core Value Proposition:**
  1. Direct manufacturer-to-farm transparent pricing.
  2. Proprietary Technical Ingredient (Active Chemical/Bio formulation) comparison engine.
  3. Bilingual Farmer UI (English + Hindi / Hinglish) with high-contrast visual cues.
  4. Multi-channel ordering (Web self-service, Toll-Free 1800-203-1425 phone booking, WhatsApp direct ordering).
  5. In-app Agronomist Crop Doctor diagnostic advisory and Acreage Dosage Calculator.
  6. Real-time APMC Mandi Bhav ticker and price discovery.
  7. 100% Genuine product guarantee with GST bill and Cash on Delivery (COD).

## Architecture
- Clean Architecture (`core/`, `data/`, `logic/`, `presentation/`).
- State Management: `flutter_bloc` with single-source-of-truth events and states.
- Web-First Responsive Design (Mobile, Tablet, Desktop).
